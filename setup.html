Node.js 20.10 or newer required

Running in under a minute

Paste one command into your AI chat ... or run it yourself. It detects supported clients, installs a private version-pinned runtime, writes the MCP configuration, and verifies all three tools.

$ npx --yes omni-vision-pro@latest setup --yes
1

Install once, from anywhere

Paste this into Codex, OpenCode, Claude Code or Cursor chat ... or your terminal:

$ npx --yes omni-vision-pro@latest setup --yes

Setup is one-time. Adding an API key later never touches your client config.

2

Add AI vision ... optional

Pick Gemini or OpenAI through a friendly menu and paste your key into a hidden prompt:

$ npx --yes omni-vision-pro@latest provider

Or import a copied key safely from chat ... it never touches shell history:

$ npx --yes omni-vision-pro@latest provider set --from-clipboard
3

Restart, reload & ask

Reload your AI client, then just say ...

“Use omni-vision-pro to analyze this screenshot. Return the visible text, UI hierarchy, layout, colors, interactions, accessibility issues, and reusable components.”

With no cloud key, images are processed locally with Tesseract OCR ... free and private.

Health check

Verify setup at any time:

$ npx --yes omni-vision-pro@latest doctor

Also supports doctor cursor.

Requirements

  • Node.js 20.10+
  • One of the supported AI clients
  • Zero API keys to begin

Uninstall

Removes only installer-managed entries and keeps your private .env, so reinstalling never loses credentials.

$ npx --yes omni-vision-pro@latest uninstall --all

Delete the private .env file separately to erase stored keys.

Command reference

Full control from the terminal

Provider settings and client setup are separate ... install once, then switch providers whenever you like.

setup --yes

Detect clients, install runtime, write config, verify tools.

setup

Guided client-selection prompt.

provider

Friendly menu for keys & mode switching.

provider status

Show active mode without revealing keys.

provider on / off

Toggle AI vision; keys are kept for later.

provider use gemini|openai|auto

Choose how configured providers are used.

provider set / replace

Add or replace a key via hidden prompt.

provider set --from-clipboard

Import a copied key ... never in shell history.

provider remove gemini|openai|all

Delete saved keys from private settings.

doctor

Verify setup & client entries.

uninstall / uninstall --all

Remove only installer-managed entries; keep keys.

serve

Launch the MCP server (stdio).

One command. All clients.

Skip the manual work ... let the installer detect, configure and verify everything for you.
