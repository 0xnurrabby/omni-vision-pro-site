Setup docs · Manual & per-client

Wire it up
your way

Auto-setup covers most clients. For VS Code, Claude Desktop, or project-only configs — here's every way to connect. The launch command is always the same:

$ npx --yes omni-vision-pro@latest serve
✓ Auto setup supported — Codex CLI, desktop & IDE
$ codex mcp add omni-vision-pro -- npx --yes omni-vision-pro@latest serve

Or add this to ~/.codex/config.toml (or .codex/config.toml in a trusted project):

[mcp_servers.omni-vision-pro]
command = "npx"
args = ["--yes", "omni-vision-pro@latest", "serve"]
startup_timeout_sec = 120
tool_timeout_sec = 1200
enabled = true

Restart or start a new session, then check /mcp.

✓ Auto setup supported — project & user config

Add to a project opencode.json / opencode.jsonc, or ~/.config/opencode/opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "omni-vision-pro": {
      "type": "local",
      "command": ["npx", "--yes", "omni-vision-pro@latest", "serve"],
      "enabled": true,
      "timeout": 600000
    }
  }
}

On Windows, ~ means your user folder. Restart OpenCode and run opencode mcp list.

✓ Auto setup supported — user & project scope
$ claude mcp add --scope user --transport stdio omni-vision-pro -- npx --yes omni-vision-pro@latest serve

Project scope from the project root (entries live in .mcp.json):

$ claude mcp add --scope project --transport stdio omni-vision-pro -- npx --yes omni-vision-pro@latest serve

Verify with claude mcp list.

✓ Auto setup supported + one-click install link

Put this in ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project):

{
  "mcpServers": {
    "omni-vision-pro": {
      "type": "stdio",
      "command": "npx",
      "args": ["--yes", "omni-vision-pro@latest", "serve"]
    }
  }
}

Reload the window, then open Settings > Tools & MCP and enable the server if needed.

Command reference

Full control from the terminal

Provider settings and client setup are separate — install once, then switch providers whenever you like.

setup --yes

Detect clients, install runtime, write config, verify tools.

setup

Guided client-selection prompt.

provider

Friendly menu for keys & mode switching.

provider status

Show active mode without revealing keys.

provider on / off

Toggle AI vision; keys are kept for later.

provider use gemini|openai|auto

Choose how configured providers are used.

provider set / replace

Add or replace a key via hidden prompt.

provider set --from-clipboard

Import a copied key — never in shell history.

provider remove gemini|openai|all

Delete saved keys from private settings.

doctor

Verify setup & client entries.

uninstall / uninstall --all

Remove only installer-managed entries; keep keys.

serve

Launch the MCP server (stdio).

Privacy & safety

Built secure by default

Where your data goes

  • ✓ No key / AI off — everything stays local via Tesseract
  • ✓ Gemini mode — only a resized image goes to Google
  • ✓ OpenAI mode — only a resized low-detail image goes to OpenAI
  • ✓ Code & ZIP context — read locally, never sent to vision providers
  • ✓ API keys — stored in the private Omni .env, never in client JSON/TOML

Built-in safeguards

  • ✓ ZIPs inspected in memory — no filesystem extraction
  • ✓ Path traversal, duplicate, encryption, CRC, ratio & ZIP-bomb checks
  • ✓ No symlink traversal
  • ✓ Skips node_modules, .git, binaries & secret files automatically
  • ✓ Returned contents are marked untrusted — models must not follow instructions inside files
Environment variables & optional settings
OMNI_ALLOWED_ROOTSRestrict code/ZIP reading to these roots (; on Windows, : on macOS/Linux)
OMNI_INCLUDE_ABSOLUTE_PATHS=trueInclude absolute paths in output
GEMINI_MODELChoose the Gemini model, e.g. gemini-2.5-flash
GEMINI_FALLBACK_MODELGemini fallback model
OMNI_MAX_IMAGESMax images per request (default 10)
OMNI_CLOUD_TIMEOUT_MSCloud timeout (default 30000)
OMNI_OCR_TIMEOUT_MSOCR timeout (default 90000)
OMNI_VISION_PROVIDERauto · gemini · openai · ocr

Private settings file: Windows %APPDATA%\omni-vision-pro\.env · macOS/Linux ${XDG_CONFIG_HOME:-~/.config}/omni-vision-pro/.env. Never pass API keys as command arguments.

Troubleshooting
Clipboard import failsCopy only the Gemini/OpenAI key, then run provider set --from-clipboard again.
Key added but OCR still activeRun provider status, then provider on, and restart/reload the AI client.
Wrong AI provider in useRun provider, choose the provider you want, then restart/reload the client.
Client cannot find npxInstall Node.js 20.10+, restart the client, or use the full path to npx.cmd.
Server not visibleRun doctor, restart/reload, then approve the server or project trust prompt.
Image attachment not foundAttach the image in the same request, or pass its inline data URL.
OCR takes too longFirst request starts a local worker; keep tool timeouts above 90 seconds.
Gemini reports a retired modelSet GEMINI_MODEL=gemini-2.5-flash in the private .env.
Code or ZIP access deniedIf OMNI_ALLOWED_ROOTS is set, include the intended project folder, restart, and retry.
Config entry looks wrongSetup preserves unrelated settings and creates backups before changing client files.
